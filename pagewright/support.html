Support

Contact

To report a problem or ask a question, open an issue at github.com/AaronOptimus/AaronOptimus.github.io/issues (a free GitHub account is needed). Please say which tool you used and what happened. Don't attach private documents.

A PDF won't open

If Pagewright says a file is password-protected, remove the password first, then try again. If it says the file is locked against changes by its author, Pagewright respects that and won't edit it.

Where are my files saved?

Pagewright always asks where to save and writes a new file, so your original stays as it was.

Pagewright Pro

Pagewright Pro is an optional one-time purchase in the Microsoft Store, when it's on sale. If you bought it and it isn't unlocked, make sure you're signed in to the Microsoft Store with the same Microsoft account, then choose Check again on the Pro page in Pagewright. If Pagewright shows no Pro tools at all, connect to the internet and restart Pagewright so it can check with the Microsoft Store. Refunds are handled by the Microsoft Store.

Privacy

Pagewright works offline and collects no data. Read the privacy policy.
